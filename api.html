Authentication

Access to the KORRA API is secured via secret merchant keys. You must include your key in the X-API-Key header of every technical handshake.

Copy
# Example request using cURL
curl -X POST "https://korra.work/api/v2/measurements/extract" \
  -H "X-API-Key: YOUR_SECRET_KEY" \
  -F "front=@front_photo.jpg" \
  -F "side=@side_photo.jpg" \
  -F "height=180" \
  -F "gender=male"

Biometric Extraction

The core endpoint for 3D body regression. Our vision engine analyzes front and side silhouettes to return over 85 personalized measurements with clinical-grade precision.

POST /measurements/extract

Accepts multipart/form-data with image files and returns a structured JSON object of body perimeters.

Copy
{
  "success": true,
  "measurements": {

  },
  "scan_id": "korra_v2_f8d2..."
}

AI Consultation

Interrogate scan data using our multi-LLM fallback chain. Get professional fit advice and style recommendations based on real biological measurements.

POST /ai/assist

Sends a natural language prompt along with measurement context to generate insights.

3D Body Models

Generate high-fidelity binary 3D vertex data directly on the server. Optimized for Three.js and custom garment design engines.

POST /body-shape/compute

Evaluates complex blendshapes and returns a Float32Array of 13,334 vertices in 60ms.

Webhooks & Security

POST /webhooks/register

Register your endpoint to receive automated scan_completed notifications.

VERIFICATION REQUIRED

All payloads are signed with your secret key. Use HMAC SHA256 to verify the X-KORRA-Signature header.
